# Bastion Repository Structure Standard

## 1. Назначение

Настоящий документ определяет официальный стандарт структуры репозитория проекта Bastion.

Цели документа:

- установить единые правила организации каталогов и файлов;
- обеспечить единообразную структуру проекта;
- исключить хаотичное создание новых каталогов и документов;
- определить порядок внесения изменений в структуру репозитория;
- обеспечить удобство сопровождения, масштабирования и коллективной разработки проекта.

Все изменения структуры репозитория допускаются только после утверждения соответствующих изменений в настоящем документе.

## 2. Общие правила

При организации структуры репозитория проекта Bastion применяются следующие правила.

### 2.1 Единая структура

Все каталоги и файлы проекта должны размещаться только в соответствии с утвержденной структурой репозитория.

Создание файлов или каталогов вне утвержденной структуры запрещается.

### 2.2 Единственный источник истины

Настоящий документ является официальным стандартом структуры репозитория.

При возникновении противоречий между документами приоритет имеет настоящий стандарт до момента принятия нового архитектурного решения (ADR).

### 2.3 Изменение структуры

Любое изменение структуры репозитория должно проходить следующий процесс:

1. Подготовка предложения.
2. Архитектурная проверка.
3. Согласование владельцем проекта.
4. Обновление настоящего документа.
5. Реализация изменений.

### 2.4 Соответствие документации

Структура репозитория должна соответствовать:

- архитектурной документации;
- дорожной карте проекта;
- принятым архитектурным решениям (ADR);
- стандартам проекта.

### 2.5 Контроль качества

После каждого изменения структуры выполняется:

- техническая проверка;
- архитектурная проверка;
- повторная независимая проверка.

Только после успешного завершения всех проверок изменение считается принятым.



## 3. Структура репозитория

Корневой каталог репозитория содержит только утвержденные каталоги и файлы проекта.

Базовая структура:

```text
/
├── docs/
├── src/
├── tests/
├── tools/
├── scripts/
├── infrastructure/
├── .github/
├── .gitignore
├── README.md
└── CHANGELOG.md
```

Назначение каждого каталога и файла описывается в соответствующих стандартах и архитектурной документации.
